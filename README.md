# JobBridge – Job Portal (MERN Stack)

## Project Description

JobBridge is a full-stack web application designed to connect job seekers with employers through an online job portal.

Job seekers can browse available job listings, view job details, and apply for suitable jobs. Employers can create, update, and manage job listings and view received applications.

The project is developed using the MERN stack:

- MongoDB
- Express.js
- React.js
- Node.js

The main objective of JobBridge is to provide a simple, organized, and user-friendly platform that makes the job search and recruitment process easier.
